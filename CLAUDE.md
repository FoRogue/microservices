# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Статус репозитория

Это учебный репозиторий по курсу микросервисов. На данный момент в нём есть только README с описанием планируемой работы — исходного кода, файлов сборки или тестов ещё нет.

## Планируемый объём работы (part1)

Три независимых микросервиса на Go, каждый со своей БД и Docker-контейнером, без связи друг с другом. На каждом сервисе — Swagger (OpenAPI) документация.

- `auth-service` — авторизация/регистрация пользователей
- `catalog-service` — каталог товаров + корзина
- `payment-service` — оплата

Поскольку сервисы независимы (без межсервисного взаимодействия в part1), ожидается, что каждый будет жить в своей директории со своим `go.mod`, Dockerfile и базой данных, а не в общем корневом модуле.

## Работа в этом репозитории

Пока кода нет, здесь нечего документировать в плане команд сборки/линтинга/тестирования. Когда сервисы будут созданы, обнови этот файл реальными командами (например, `go build`, `go test ./...`, `docker compose up`) и архитектурными заметками по каждому сервису.
